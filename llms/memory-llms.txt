# Memory (Timely)

> Memory AS, operating as Timely (timely.com), is an Oslo, Norway based software company behind Timely — an AI-powered automatic time tracking and timesheet platform for consultancies, agencies, professional-services firms and SaaS teams. Its Memory engine passively captures work across the apps a person uses and AutoSheet auto-completes timesheets. Timely exposes a REST API at api.timelyapp.com (version 1.1) secured with OAuth 2.0.

## API
- [Timely API base](https://api.timelyapp.com/1.1): REST API (v1.1), OAuth 2.0 bearer auth, for accounts, projects, clients, users, events (time entries), labels and reports.
- [Developer portal / API reference](https://developer.timely.com/): full reference behind authenticated login (app.timelyapp.com/auth/docs).

## Authentication
- OAuth 2.0 authorization-code flow; authorize endpoint redirects to [app.timelyapp.com/oauth/authorize](https://app.timelyapp.com/oauth/authorize).
- See authentication/memory-authentication.yml in this repo.
